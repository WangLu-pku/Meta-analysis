## Reproducible Analysis

This repository contains the study-level data extracted from the included studies and the R code used to conduct the meta-analyses reported in this systematic review. Each data entry includes a study identifier to ensure traceability to the original study.

The R Markdown file (`reproducible_analysis.Rmd`) documents the data processing procedures and statistical analyses. The corresponding HTML report (`reproducible_analysis.html`) provides the analysis code and outputs for reference. 

To reproduce the analyses, download or clone this repository, install the required R packages, and run `reproducible_analysis.Rmd` from the repository's root directory.
